# S# SkillUp AI – Job Skill Gap Analyzer

## Project Overview
SkillUp AI is a career development web application built using Python and Streamlit. It helps users compare their existing skills with the skills required for a selected job role, identify missing skills, and explore learning recommendations.

## Features
- Job role selection
- Existing skill selection
- Matched and missing skill identification
- Skill gap analysis
- Learning recommendations

## Technologies Used
- Python
- Streamlit
- Pandas
- CSV-based skill data

## How to Run Locally
1. Clone this repository.
2. Install the required dependencies:
   `pip install -r requirements.txt`
3. Run the Streamlit application:
   `streamlit run app/app.py`
