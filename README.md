# SkillUp AI — Job Skill Gap Analyzer

## Project Overview

SkillUp AI is a career guidance application developed to help students and fresh graduates identify skill gaps between their existing technical skills and the requirements of their target job roles.

The application compares user-provided skills with job-specific requirements, calculates a skill match percentage, identifies missing skills, and provides relevant learning resources to support career development.

## Objectives

- Identify the technical skills required for different job roles.
- Compare existing skills with job-specific requirements.
- Calculate skill match percentages.
- Identify missing skills and areas for improvement.
- Recommend learning resources for skill development.
- Support informed career planning.

## Key Features

- **Demo Login:** Provides a basic sign-in interface.
- **Skill Gap Analysis:** Compares existing skills with the selected job role.
- **Skill Match Percentage:** Displays the proportion of required skills matched.
- **Missing Skill Identification:** Highlights skills that require further development.
- **Learning Resource Recommendations:** Displays relevant resources for missing skills.
- **Skill Exploration:** Allows users to explore available skills.
- **Interactive Dashboard:** Presents analysis results through a Streamlit interface.

## Installation and Execution

### Clone the Repository

```bash
git clone https://github.com/sundarimuruganandam/SkillUp-AI-Skill-Gap-Analyzer.git
cd SkillUp-AI-Skill-Gap-Analyzer
```

### Install Dependencies

```bash
python -m pip install -r requirements.txt
```

### Run the Application

```bash
python -m streamlit run app/app.py
```

After execution, open the local URL displayed in the terminal.

## Application Workflow

1. Access the application through the sign-in interface.
2. Enter existing technical skills.
3. Select a target job role.
4. Run the skill gap analysis.
5. Review the skill match percentage.
6. Identify matched and missing skills.
7. Explore the available learning resources.

## Limitations

- Results depend on the skills and job-role information available in the dataset.
- Recommendations are limited to the resources included in the application.
- The demo login is not intended for production use.
- Skill match percentages do not guarantee job readiness or employment.
